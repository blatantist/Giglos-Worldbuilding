## Overview

Quick definitions for entity linking, copied from the source glossary. The source gives no chat codes here, so entries cite `(source glossary)`. Entries marked "[Z] concept, [C] label" keep both tags as written: the idea is Zach's, the name is Claude's.

## Canon

- **Aeration**: Whipping cytoplasm into foam to gain volume at constant mass [Z] (source glossary). See [body-and-growth](../biology/body-and-growth.md).
- **Aspirant**: Middle-ring agent whose goals route through entering the inner ring [Z] concept, [C] label (source glossary). See [goap-architecture](../agents/goap-architecture.md).
- **Blackboard**: Per-agent and shared GOAP state; mirrors lineage memory sharing [Z] (source glossary). See [goap-architecture](../agents/goap-architecture.md).
- **Boeda paper**: Multi-Agent Cooperation in Games with GOAP, AIIDE 2021 [Z] (source glossary). See [prior-art](../project/prior-art.md).
- **Clean split**: Controlled mitosis choosing what each half keeps; elite-trained [Z] (source glossary). See [education-and-clean-splitting](../society/education-and-clean-splitting.md).
- **Degenerate mitosis**: Involuntary split from chronic deflation [Z] (source glossary). See [dissolution-and-death](../biology/dissolution-and-death.md).
- **Dissolution / collapse**: Uncontrolled cascading mitosis ending in goop and powder [Z] (source glossary). See [dissolution-and-death](../biology/dissolution-and-death.md).
- **Doctrine**: Beliefs about what splitting means; also what agents will not question [Z] (source glossary). See [identity-doctrines](../society/identity-doctrines.md), [reflection-and-persuasion](../agents/reflection-and-persuasion.md).
- **Founding-plot split**: The founding-plot split into a perfect fascist leader and a "weak" protagonist half [Z] concept, [C] label (source glossary). See [premise-and-protagonist](../game/premise-and-protagonist.md).
- **Forced splitting**: Torture-induced splitting to extract confessions or purge dissent [Z] (source glossary). See [state-repression](../society/state-repression.md).
- **Frame and foam**: Cartilaginous structural tissue and foamy muscle-like tissue [Z] (source glossary). See [body-and-growth](../biology/body-and-growth.md).
- **Fusion**: Merging two compatible Giglians; gene mixing, marriage analog [Z] (source glossary). See [fusion](../biology/fusion.md).
- **Giggle**: English label for the Giglian vocalization; speech is controlled giggling [Z] (source glossary). See [joy-and-mood](../society/joy-and-mood.md).
- **Glaggle**: Meme smiley that inspired the Giglian head and base form [Z] (source glossary). See [naming-and-terminology](../world/naming-and-terminology.md).
- **Glasgo**: The protagonist; the part trimmed from the "founder" tip in a forced, targeted mitose, with the skill but not the memory [Z] (N). See [premise-and-protagonist](../game/premise-and-protagonist.md).
- **GOAP / LGOAP**: Goal-oriented action planning; LGOAP adds long-horizon plan influence [Z] (source glossary). See [goap-architecture](../agents/goap-architecture.md).
- **Greedy mitosis**: Deliberately unequal split; presumed intentional in law [Z] (source glossary). See [law-and-courts](../society/law-and-courts.md).
- **Hedons**: Zach's word for the hedonistic lazy elites, who pretend to be skilled because of their large tanks [Z] (N). See [government-and-founder](../society/government-and-founder.md).
- **Holding pressure**: Maintained healthy baseline; cultural metaphor [Z] (source glossary). See [joy-and-mood](../society/joy-and-mood.md).
- **Jev**: Zach's separate decision model over up to 255 labeled options [Z] (source glossary). See [jev](../agents/jev.md).
- **Joy**: Core moral tenet; outward-growing healthy baseline [Z] (source glossary). See [joy-and-mood](../society/joy-and-mood.md).
- **Leaky**: Folk description of depression [Z] (source glossary). See [joy-and-mood](../society/joy-and-mood.md).
- **Middle ring**: Managers of logistics; manage but do not own [Z] (source glossary). See [the-city](../society/the-city.md).
- **Purge by mitose**: State extraction of dissent into a disposable half [C+] (source glossary). See [state-repression](../society/state-repression.md).
- **Shadow agent**: The player's GOAP agent that never acts, scored against the human [Z] concept, [C] label (source glossary). See [player-agent-and-dialogue](../game/player-agent-and-dialogue.md).
- **Skill transplant / harvest**: Ruler fuses with a skilled donor then splits off the waste half [Z] (source glossary). See [state-repression](../society/state-repression.md).
- **Stealth path**: Persuading the inner ring without triggering threat labels [Z] (source glossary). See [resistance](../society/resistance.md).
- **The Founder**: Living descendant fewest splits from the original founder [Z] (source glossary). See [government-and-founder](../society/government-and-founder.md).
- **Waste half**: Cast-off remainder of a skill harvest [Z] (source glossary). See [state-repression](../society/state-repression.md).
